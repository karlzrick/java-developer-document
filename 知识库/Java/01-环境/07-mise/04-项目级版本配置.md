# 项目级版本配置

## 1. 设置项目版本

进入项目根目录：

```shell
cd /path/to/project
mise use java@temurin-21 node@24.11.0
```

命令会生成 `mise.toml`：

```toml
[tools]
java = "temurin-21"
node = "24.11.0"
```

## 2. 安装项目工具

团队成员拉取项目后执行：

```shell
mise install
```

## 3. 检查

```shell
mise ls --current
java -version
node -v
```

建议将 `mise.toml` 提交到 Git。
