# 项目级版本配置

## 1. 设置项目版本 -- 开发人员A操作

进入项目根目录：

```shell
cd /path/to/project
mise use java@temurin-21 node@24.11.0
```

命令会生成 `mise.toml`：

```toml
[tools]
java = "temurin-21"
node = "24.11.0"
```

## 2. 安装项目工具 -- 开发人员B操作

团队成员拉取项目后执行：

```shell
cd /path/to/project

mise trust            # 信任当前目录找到的 mise.toml，用于第一次进项目，允许配置生效 → 安全授权
mise trust --show     # 查看信任状态
mise trust --untrust  # 取消信任

mise install          # 把 mise.toml 里锁的版本全装上  → 装包动作
```

## 3. 检查

```shell
mise ls --current     # 确认 java/node 等已是项目指定版本
java -version
node -v
```

建议将 `mise.toml` 提交到 Git。
